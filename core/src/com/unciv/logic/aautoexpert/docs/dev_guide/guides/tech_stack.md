# Technology Stack

## Development Environment

- **Primary IDE**: **VS Code**
  - Utilize appropriate extensions for Kotlin and Android development.

## Languages and Tools

- **Kotlin**
- **Gradle** (using Kotlin DSL)
- **Android Gradle Plugin**
- **VS Code** (with extensions)
  
## Libraries and Frameworks

- **Kotlinx Serialization**
- **Ktor**
- **JUnit**
- **Mockito**
- **Detekt**
- **Logback**
- **Clikt**
- **JNA (Java Native Access)**
- **Java Discord RPC**

## Build System

- **Gradle** configured with **Kotlin DSL**.
- Ensure all code adheres to the configurations and dependencies managed by Gradle.

## External Tools Integration

- **Java Discord RPC** for integrating Discord functionalities.
- **Profiling Tools** for performance analysis.

## Version Control Practices

- **Use Git** for version control.
- **Maintain separate branches** for features, bug fixes, and releases.
- **Regularly merge and review** to prevent codebase conflicts.
